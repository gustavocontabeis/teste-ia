# Calculadora

Este projeto é uma simples calculadora desenvolvida em Java.

## Pré-requisitos
- Java 8 ou superior
- Maven 3.6 ou superior

## Instruções de Execução
1. Clone este repositório.
2. Navegue até o diretório raiz do projeto.
3. Execute o comando `mvn clean package` para construir o projeto.
4. Após a construção, você encontrará um JAR executável no diretório `target`.
5. Execute o JAR gerado com o seguinte comando:
   ```
   java -jar target/calculadora-1.0.jar
   ```
